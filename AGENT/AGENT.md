# AGENT.md — 海上异构无人集群项目

> 项目背景包版本：2.0；当前阶段决定更新于2026-09-18。用户最新冻结方案见[plan.md](../plan.md)，优先于V2历史选型建议。本文不是已实现系统或理论验收报告。

## 1. 项目做什么

建立**母船统筹、各航行器独立执行的海上异构无人集群任务与编队作业系统**。输入结构化任务、平台/资源配置、已知地图及实际可用状态，完成任务分配、资源与时间安排、必要的协同/编队、路径与轨迹规划、平台相关控制，以及执行反馈和计划修复。

协同是为了完成任务，不是要求所有类型的航行器始终同步、保持同一个队形。第一版用一个近海多区段巡检/调查场景串起完整闭环，场景中有多项子任务，而非一个固定目标点。

**不做业务图像或声呐识别、珊瑚/风机缺陷诊断、业务载荷选型、SLAM及定位算法研发。**作业要求由外部输入。传感器未知不阻塞任务控制研究，也不能据此虚构载荷、定位或网关能力。

## 5. 最少但不可省略的集成检查

一次任务只有一个在线主调度器；同一平台同一时刻只有一个生效的运动后端和一个权威动力学状态源。不要让两个原始模拟器同时推进同一机器人。

沿用上游接口，但核对ID、坐标/单位、时间、命令层级、开始/完成/取消含义。先做“任务动作→原生目标”和“实际结果→原生反馈”两个方向的适配；没有依据不新增接口。原局部规划器没有旅行时间查询服务时，不虚称已有该能力，可先使用原估计和实际延迟修复。

本机可以经本机状态接口读取自己的仿真状态；邻机信息只能来自实际收到的消息。已知地图可预装。受限通信测试不得从世界真值、显示或共享内存绕过远程消息限制。

平台模型不能混用：不把调小UAV速度当作UUV动力学；同一AAV不同时占用两种身份；不默认欠驱动平台能悬停或任意侧移。理论保证只在对应模型与假设下使用。

原始复现保留上游模型及证据；本轮已获授权实施受限Python移植和ROS1 Noetic闭环，不要求先完成MATLAB或全部候选原例。不要同时迁移ROS/系统、修改运动算法和更换动力学。后续长期部署环境另行决定，不影响当前冻结环境。
