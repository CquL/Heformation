# 常用提示词 V2.0

这些是可复制或按路径读取的单次工作说明，不是自动创建的命令，也不授予超出本次用户请求的操作权限。先读根目录AGENT.md及当前状态。所有提示词都以“不继承旧HUC、上游原生接口最小集成”为准。

| 文件 | 什么时候用 |
|---|---|
| [00 新会话](00_session_start.md) | 接续当前工作，不重造项目方案 |
| [01 上游选型与原例定位](01_upstream_selection.md) | 按V2候选确定一个可运行上游例子，支持唯一上层选择 |
| [02 文献与源码核查](02_literature_verification.md) | 用户要求查新/核验时，回到原文与官方代码 |
| [03 原始复现](03_reproduce_upstream.md) | 执行一个上游原例，不同时重写算法 |
| [04 模型与理论](04_model_and_theory.md) | 明确研究问题后，或用户指定时，逐项改原模型 |
| [05 最小集成改动](05_implement_slice.md) | 连接两个实际接口，做一个完整动作与反馈 |
| [06 闭环实验](06_benchmark_experiment.md) | 同一场景检验正常、延迟、绕行、通信或故障 |
| [07 代码与结果审查](07_code_and_evidence_review.md) | 审查所选上游/新适配及实际证据，不审旧HUC |
| [08 原创性与证明审查](08_proof_and_novelty_review.md) | 判断问题是否已有解法、保证是否仍适用 |
| [09 更新交接](09_update_handoff.md) | 根据实际结果更新02、14、15 |

旧链接[01_repo_audit.md](01_repo_audit.md)仅保留停用说明，不执行原P0工作流。首次建议用01，随后按授权转03。上游小复现不是将完整联合协调器从第一版目标中删除。

提示词里的必要记录可以合并到一份简短报告，不要求为了完成提示词创建复杂数据库、消息包或几十份文档。
