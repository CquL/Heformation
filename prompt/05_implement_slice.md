# 实现一个最小原生接口连接

> 背景包2.0任务正文。先读项目AGENT；操作范围由本次用户授权决定。


先读AGENT.md、content/03_system_architecture.md、content/04_inputs_outputs.md及选定上游源码。只修改新集成代码与明确选定的上游适配，不引用旧HUC。

明确本次要接通哪一条链：例如任务执行器发起动作→运动后端接收原生目标→实际完成/失败回到原生任务结果。两端消息/函数、调用端和配置都实际读取，不凭文档中的概念字段创建一套新协议。

原生接口已足够则直接复用或remap；语义不一致时列出差异，再补最少映射。保持一套在线调度、一个生效后端、一个本机动力学源。核对ID、单位、坐标、时钟、命令层级、目标取消和整个任务完成规则。

以用户当前要求完成一个可运行小闭环，而不是先建许多抽象类。上层没有运动查询或下层没有任务级完成信号时，明确实现范围，不把估计说成精确预测。适配存在也不能宣称两个论文全能力相加。

执行与改动相关的最小测试，验证成功和至少一个合理失败/取消分支，保留已有原始例子。不要同时替换模型、迁移OS或增加感知。

交付修改文件、原生接口映射、真实命令/结果、剩余差距。一份说明和必要日志即可，不强制增加包络/证书/多重日志格式。
