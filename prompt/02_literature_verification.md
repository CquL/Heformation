# 核验论文与源码，服务当前选型

> 背景包2.0任务正文。先读项目AGENT；操作范围由本次用户授权决定。


先读AGENT.md、content/12_literature_review.md、content/13_references.md。V2中的核查状态是来源记录，不自动当作当前在线事实。按用户指定范围研究，旧HUC不属于检索对象。

优先查看原论文全文/作者版本、正式会议或期刊记录及官方源码。区分预印本年份、正式发表年份、后续版本和代码版本；必须核对本次要用的假设、算法、理论与实验，不以摘要或第三方issue代替。需要表格或示意图理解时实际阅读对应内容。

每个关键候选回答：解决什么问题；信息与动力学假设是什么；何种性质在什么条件下被证明；实验规模/平台和真机或仿真怎样区分；公开代码到底实现什么；与当前需求的差距；建议用于原始复现、组件、对照还是暂缓。

特别避免：Primitive等同严格编队；T-RO2023链接原仓库即表示后续全部已开源；Calvo的relay等同通信中继；CAT-ORA等同任意障碍规划；DMPC/RMADER保证任意断联；工具型项目等同控制算法。

查询新状态时可以更新来源，但标明这是新增核验，不改写V2原始快照。找不到代码写“未确认”，不能断言没有。不要让插件少量返回成为检索全集，亦不声称穷尽全部论文。

输出与选型直接相关的证据和结论、准确论文/代码链接、未确认项；按实际事实更新12/13/14，不引入全部候选作为运行依赖。
