## 五实例固定动作联调

入口：`scripts/docker_probe_five_qualification.sh`；场景是共同world坐标的ENU无障碍开发场景，海面z=0，零流参考模型。

三qn、Otter、REMUS保持独立实际积分；PVS原NED/FRD转换未改变。开发探针显式下发固定动作，尚未经过五平台模式调度器，也不计算观测/受限交付成功。

| 运行 | 结果与边界 |
|---|---|
| first-integration-r1 | 失败。返回AIR时原生ID6含NaN时长/系数，导致轨迹服务器原点参考及AIR机体包络失败 |
| invalid-poly-r1 | 四类非法多项式由真实轨迹服务器拒绝，qn保留原参考；属于接口负例 |
| finite-integration-r2 | 五个实例的7项所需原生动作全部SUCCEEDED；另1项故意冲突的AIR目标REJECTED。一台AAV完成Swarm→同qn跨介质→新Swarm |
| wire-integration-r3 | 最新five-finite-wire版本再次取得相同动作结果；独立五实例时间/域审计通过，最大漂移0.000708s |

r2独立审计：五实例时间对齐无缺样，最大模型/ROS漂移约0.006611s；三AAV最低机体代理净距约1.50m，AIR机体最低包络均高于海面。**海洋船体包络、海底/实体障碍/禁入区及五平台整体安全仍未验收**，不能从分区路径相隔较远推出全部环境安全。

PVS终态仍分别是TRIM_PROPULSION与COAST_STOP。r2中REMUS任务路径终点x=0，末态x约9.205m，再次表明滑行尾段必须进入占用和转场预测，不能在观测通过点立即释放运动中的资源。

## 原生优化提交修复及回归边界

上游L-BFGS失败会恢复返回变量，但成本回调的多项式缓存未同步恢复。新补丁重新计算返回候选，检查有限性/正时长/原碰撞条件；真实消息使用float32，转换后的系数与时长也必须可表示且有效。接收端在修改当前参考前独立拒绝非法包。

首版拒绝所有线搜索失败虽然五实例通过，却使七机实时优化的舍入停止阻塞首条轨迹。该失败保留。后续版本将明确恢复的有限迭代点重新计算和检查后作为非收敛候选，保持原近似规划语义，绝不发布失败试探缓存。最新seven-wire-r2回归PASS、185检查0失败。离线验证的全序列搜索改为等价二分查找后，同一正例完整verification JSON不变，旧失败也仍为FAIL。模块302项通过；这些数量不替代阶段出口。
