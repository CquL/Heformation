# 原生完整运动查询与接纳边界

本轮仍在G2/G3接线阶段。查询使用原PVS模型、控制器和执行器状态副本，接入现有ExecutorTravelTimeProvider；没有新增仿真器、控制器或服务端点。来源和使用边界见`research/literature/notes/native-motion-query-basis.md`。

## 实际改变

查询同时计算到目标的运动、原生减速尾段和终端保持，不再只算到目标点。它返回明确的FEASIBLE/INFEASIBLE/UNKNOWN、时间分解、终点及带时间的预测轨迹。旧模型和实际模型都不被预测重置或推进。

PVS在现有Action的接纳前阶段异步查询。物理积分继续；取消、GoalID令牌、代次及当前起点复核防止旧查询提交新任务。查询、子进程等待和传输共享同一个单调截止时刻。接纳后原取消/失败资源锁定语义保留。

低速终态也不是冻结位置。内部预测可保留完整终态模型，再推进已声明的有界等待；沿用原模型固定步，并检查等待期几何。控制器副本留在内部，不写入Goal或逐帧诊断。

## 证据

目录为`experiments/20260920-native-query/`：

| 实验 | 已证明的结果 |
|---|---|
| coast-preflight-r1 | 目标前路径清楚，但滑行尾段有coast_rock；在接纳前REJECTED/预测不可行，UUV未启动运动，实际场景审计通过 |
| pending-cancel-r1 | PENDING查询中取消得到RECALLED；模型steps继续、参考代次未增；旧查询未误提交随后正常任务 |
| query-budget-r1 | 0.001s受控查询预算耗尽得到UNKNOWN并拒绝接纳；不是数学无解，也没有启动运动 |
| normal-cost-r1 | 五实例所需动作成功、实际场景审计通过；Otter预测/实际约32.56s，UUV约62.42s，终点差0，时长差约1e-13s |

对账来自同一GoalID的接纳模型时刻、预测摘要及实际Result。它是该模型/状态的实证，不宣称所有条件均精确预测。缺场景、预算或模型时域不足仍为UNKNOWN，不提交不完整候选。305项原测试加新增查询测试共309项通过。
