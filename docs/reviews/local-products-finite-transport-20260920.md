# 本地观测、USV支援与有限接收边界

本轮接通真实PVS运动→本地几何观测→有限容量传输→现有runner接收处理。没有新建协调节点、文件传输系统或另一个任务状态源。完整联合请求的候选生成、自动支援安排和复查仍未完成。

## 当前实现

- `LocalObservationWindow`位于原`observation_coverage.py`，使用原几何可见性和请求声明的连续驻留条件。PVS/qn端点用实际完成积分的状态调用；未启动、错误介质、过期样本、时间不一致或已故障时不累计驻留。每个Goal/兴趣点只产生一次产品，不生成“已接收”事实。
- `PlatformTask.observation_ids`仅携带选定兴趣点ID；端点启动时从`/mission/request_file`加载已有请求。模型配置和几何合同不复制进每个Goal。空ID列表保持纯运动语义。原`Formation.action`不变。
- 产品经原`scene_publisher`内的仿真传输边界处理，其独立定时回调不使用渲染线程的锁。实际位置、实际介质、SOLID遮挡决定链路。0.1秒网格只使用该时刻之前的新鲜状态，缺样不给传输增量。水下共享8m/2KiB/s，AIR/SURFACE到母船共享30m/32KiB/s；不称真实设备性能。
- 通知按实际`std_msgs/String`序列化长度（UTF-8正文及4字节长度前缀）计入容量，摘要另占32KiB。所有信道同一步首更新，禁止瞬时多跳。源端观测通知到达不等于摘要已交付。
- 母船产品仅从`/mother/received_products`进入runner；`/mother/received_notifications`不会增加交付覆盖。接收处理核对请求、选定兴趣点、物理成员和对应GoalID；重复不重复计数，旧Goal或未派发活动不能更新覆盖。接收不解除活动资源锁。

设计机制沿用`docs/requirements/cooperation-source-design-20260920.md`中的信息因果、接收事件释放和预承诺会合原则；范围/速率/大小是用户冻结的实验条件，观测仍是几何代理。没有加图像、声呐评分或通信传播模型。

## 实跑证据

证据目录`experiments/20260920-local-products/`，新镜像`swarm-formation-qn:cooperation`已重建消息。

`run-r1`先验证物理与传输边界：UUV和USV都接纳PREPARED片段后才启动。UUV从(-5,8,-2)经样点(0,8,-2)通过，USV独立从(-5,-8,0)前往(4,8,0)。USV无需等待只能经自己转发的水下观测通知；二者确实同时执行。USV路径经原生PVS完整查询，包含尾段与终端，预测约99.16秒。

UUV满足1秒实际几何驻留后产生水下产品；此时母船没有收到通知或摘要。随后USV进入可用链路范围，通知先收到，32KiB摘要后收到。r1从产品产生到接收约81.65秒，两台原生Action均SUCCEEDED且终端验证成功。

`run-r2`进一步连接现有runner的产品接收处理：

| 事实 | 结果 |
|---|---|
| 产品产生时的母船交付覆盖 | 0 |
| 通知收到但摘要尚未收齐 | 不增加交付覆盖 |
| 摘要接收 | 约81.63秒后到达，同一产品身份 |
| runner交付覆盖 | 0.5：联合请求有空中和水下两个兴趣点，本轮只执行水下点 |
| 资源占用 | 接收处理没有释放UUV/USV成员 |
| 原生运动 | UUV、USV均SUCCEEDED，terminal_verified=true |

精确0.1秒网格的最终代码用r2记录的实际状态进行了传输重放：通知时间1789924614.5，摘要时间1789924630.5，判据通过。**该项是实跑数据重放，不是第三次动力学实跑**。首两轮实时传输定时器采用约0.1秒实际回调时刻；该差异明确保留。

`transport-result.json`、`handover.bag`与`grid-replay.json`保存相应证据。最终329项模块检查通过，重点新增检查为本地缺样/介质/连续驻留和接收Goal身份/幂等/不解锁，而非按函数补齐测试。

## 未完成与使用限制

`monitoring_request_joint.yaml`现可被本地观测合同与传输边界加载，但原AIR专用任务展开仍会拒绝它；不能使用旧三机入口宣称完成这个请求。

本轮路径由边界实验预先给定，尚不是优化器选择的USV支援计划。正常运动Result结束后的跨平台执行承诺、完整返回、至多一轮复查、AIR本地产品、有限通信下的远端状态/控制结果网关，以及任务预览版本确认仍需继续接线。runner旧的直接Odometry/Action结果通路尚未成为受限通信的母船知识模型，不能把本次产品接收隔离推广为所有远端消息都已隔离。

全程运动冲突/时间安全总验收、AAV完整查询10秒预算、Swarm只读查询、编队方法比较及科研对照继续保留未完成。原失败、旧三机/七机入口不删除。
