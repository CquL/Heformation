# 通信约束接入与当前业务运行

日期：2026-10-09。本文记录实施事实；完整验收结论以同次任务终态、实收和返回记录为准。

## 已接入的行为

原场景使用集中声明的8m声学／30m无线范围、2KiB/s声学／32KiB/s无线速率；范围图和传播时间是缩比演示模型。原有限账本增加在途前缀、共享公平预算和各跳传输记录。接收前不能转发，暂时断开时保留缓存。

原任务权威在派发前计量并传递有限动作清单，命令确认经过有限回传。巡视期间只执行已授权动作；母船计划使用实收状态，执行进度通过有限反馈更新。Swarm邻机多项式参考经过独立接收话题和相同无线容量，不再使用理想广播接收路径。

USV服务分为本地收集、必要携带、上传。收集阶段等待与规定报告匹配的本地终态包，上传阶段确认母船实收；不会要求母船先收到才允许USV开始上传运动。人工返航需要下行服务时，USV先缓存待传命令，在声明服务位置交付并收集确认，再回到上传范围；原Swarm返航和各模型继续执行实际运动。

这些行为在既有Plan、Action和执行线程内实现。首次业务及返回保留一个任务权威和物理成员占用；报告和消息不能替代实际动作终态。
