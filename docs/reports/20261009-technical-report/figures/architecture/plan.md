# 图1绘制计划

- 画布432×246pt，报告插入宽度14.65cm；字号10／9／8.5pt，边框0.6pt，主路径0.9pt。
- 左列：作业与状态输入。中列：模型、重点联合决策与Plan。右列：确认／派发及AIR、WATER、USV三个原后端。
- 底部：实际反馈、任务闭合与同源Qt／RViz。回路从底部沿最右侧和上侧留白返回，虚线只表示剩余作业调整，不穿过标题或主链。
- 原后端浅灰、本研究组织浅蓝、只有联合决策深蓝白字；区域透明，不加渐变、阴影或无关图标。
- 右侧三个模式后端共享Action派发的正交分支；这是逻辑分支，不暗示同一物理成员同时执行两种模式。
- 三条派发边共用同一总线起点；几何检查的tail-near-line警告是该明示扇出的重复尾点，不是经过外部标签的连线。执行分区到实际反馈的边以分区为源，明确汇聚三个模式。
- 需要的中文高度略大于双栏横条默认值，因此保留246pt高，以适应报告而非两栏论文页面；比例在插图宽度下保持不变。

## 预览核对

1. 输入—模型—决策—Plan—执行主线是否清楚；实际回路是否独立。
2. 中文、英文后端标签是否越界或覆盖箭头。
3. AIR／WATER／USV标签是否保持灰色，只有联合决策为强强调。
4. 所有箭头是否有箭头，虚线是否只承担一种语义。
5. 原后端与项目组织是否区分，没有把基础算法写成原创。
6. 在14.65cm报告宽度下是否仍可读，图题与图在同页。
