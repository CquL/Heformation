# 项目背景与研究边界

**背景包2.0｜2026-09-15｜依据：用户明确要求、V2实施方案、原始报告截图。**

## 1. 项目定位

面向近海海岛、风机、平台等作业背景，研究异构无人航行器如何分配任务和资源、怎样协作运动与执行、执行变化后怎样调整。母船是任务统筹中心，各航行器具有本地执行与控制能力。

项目不是把所有机器人始终组织成一个编队，也不是只完成“输入终点，输出五条轨迹”。最终要形成从任务输入到实际完成的系统，并在可重复实验基础上发展自己的方法。

## 2. 工作范围

包括：结构化任务建模与必要的任务方法选择、任务分配、能源/时间/平台资源调度、并行和接替协作、按需编队、路径与轨迹规划、避碰、平台控制、状态和结果反馈、通信条件下的修复。

不包括：业务图像/声呐识别、珊瑚白化或风机缺陷诊断、业务载荷选型、SLAM或定位算法研发。可以接收外部产生的新任务、地图或作业要求，但不能把这些接口说成已经实现业务识别。

第一版任务由文件、面板或外部系统给定。未知传感器不妨碍开展控制侧研究；任务资格与模型参数按可用资料配置，未知部分明确为仿真假设。

## 3. “协同”与“编队”

并行巡检、作业接替、共享作业区错峰使用，都属于任务协同。编队是需要相对几何关系的一类运动动作。某段任务需要编队时，由符合该动作条件的子团队执行；其他平台仍可独立工作。

母船统一分配不妨碍局部规划分布式运行。母船给任务/目标/时序，平台以自己的状态和收到的邻机信息执行。系统不依赖母船跨网络维持所有平台的高频姿态或执行器环。

## 4. 报告目标与当前完成度

用户提供的[控制理论指标截图](sources/report_control_requirements.png)写有：适用于不少于5个航行器、空中/海面/海下三种场景的协同作业；数值仿真协同作业位置误差小于2 m、姿态误差小于0.5°；实物测试结合任务完成度和实际跟踪误差评测。

[路径规划成果截图](sources/report_planning_patent.png)列有“异构无人航行器集群路径自主规划方法”“国内发明专利”“受理”等目标。

这些是用户材料中的项目目标，不是当前测试结果。截图没有给出最大误差/均方根等全部统计口径，也不能据此断言专利已经申请或受理。物理模型不提供的姿态指标不得填0冒充验证。

第一版用一个多子任务场景验证完整链路；中间可以先用UAV调试，但在覆盖对应模型以前，不称为完整空水潜验证。最终五节点的具体平台组成、可用模式和参数仍待冻结。

## 5. 工程路线的当前决定

不再读取、审计或继承旧HUC。独立复现少量有价值的论文成果，使用原生接口和最薄动作适配形成新组合系统，再由实验识别问题。

当前只有Swarm-Formation的复现由用户确认。新选框架的论文与源码已有V2核查记录，但本地运行、彼此适配、海洋后端以及新理论尚未完成。
