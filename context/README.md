## 使用原则

状态更新以02和15为准；稳定的范围与选择以14为准。架构和研究页是拟实施内容，不作为自动完成标记。

论文事实由V2核查记录支撑；上游源码复现的实时结果以[16](16_upstream_reproduction_status.md)为准。源码副本仍保留各自的内部版本信息。

[来源原文](sources/README.md)只按需读取。[三种简短模板](templates/README.md)可选使用，不要求每次运行都填满文档，不改变原生消息接口。

旧V1中的继承条款已经废止，不能从旧缓存恢复为当前规则。此次不重新定义完整优化问题，也不新增所有平台共用的数据包/控制器。
