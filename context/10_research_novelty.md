# 研究问题与创新状态

## 1. 当前原则

目前仍处在**建立可信系统基线和发现真实缺口**阶段。

组合开源组件、修接口、把任务线跑通本身不是论文创新。

任何“新理论”必须回答：

- 现有方法为什么不够；
- 缺口能否形式化；
- 新方法比什么 baseline 好；
- 哪些假设下成立；
- 有何实验或理论证据。

## 2. 当前三个候选研究问题

### Task–Information–Motion coupling

任务是否能开始不仅取决于机器人空闲，还可能取决于：

```text
required information received
```

而信息到达又受平台位置和通信机会影响。

这可能形成：

```text
Task
↔ Information
↔ Motion
```

但当前只实现了 Observation / Delivery 的语义分离，尚未实现通信联合优化。

### 异构角色选择

未来同一 USV 可能同时具备：

```text
surface inspection
relay
rendezvous
data aggregation
localization support
```

问题是“执行什么任务”和“承担什么角色”是否需要同一优化循环选择。

当前尚未实现。

### 由任务安全与动力学反推通信 deadline

不是固定“每 N 秒通信”，而是根据：

- 平台运动速度；
- 状态不确定性；
- 安全余量；
- 下游任务所需信息；

反推最长允许信息年龄。

当前仍是研究候选。

## 3. 当前已经被工程证实的重要问题

虽然不是创新结论，但以下问题已经在工程中真实暴露：

- 固定七机假设放错层会阻塞三机子集执行；
- “终点正确”不能证明 formation optimizer 真正参与；
- 单机任务后如果模式不复位，组级编队项会被关闭；
- Executor 按逻辑单元存位置会破坏共享物理成员预测；
- 只看末态无法发现中途散队或走廊偏离；
- “received” 不自动蕴含“observed”；
- Action 落点正确不等于 Result 已返回。

这些是后续形成研究问题的有效工程证据。

## 4. 当前不能宣称

不能写：

- 已提出新的任务—信息—控制统一理论；
- 已证明通信感知调度优于现有方法；
- 已完成五平台联合优化；
- 当前解析观测模型是新的感知算法；
- 当前工程适配就是论文核心创新。

研究创新应在五平台和受限通信问题真正进入实验后再冻结。
