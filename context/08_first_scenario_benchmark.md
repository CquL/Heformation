# 第一版场景：近岸监测 AAV 子系统

**更新：2026-09-19**

## 1. 场景定位

第一版业务语义场景不是七机 A→B→Return。

当前冻结场景：

> **近岸分层巡航监测中的 AAV 子系统验证**

在线执行：

```text
3 AAV
```

目标资源模型还声明：

```text
1 USV
1 UUV
```

但 USV/UUV 当前 offline-only，不产生实际完成事件。

## 3. 单机巡查

区域 A/B/C 的普通监测任务由单机 Executor 执行。

一次观测位置可以覆盖多个兴趣点，因此展开航点数由覆盖需求决定。

当前代理：

```text
cruise altitude = 0.8 m
horizontal footprint radius = 2.5 m
continuous dwell = 1.0 s
LOS obstacle check = enabled
```

这些数值是当前请求明确声明的几何/驻留条件，不是相机参数，也不是论文提供的通用阈值。
2026-09-19 最新决定：删除曝光、模糊及距离分辨率衰减评分，不再用任意正分数制造“有效图像”。
输出是几何观测代理；真实曝光、像素分辨率与图像质量尚未验证。

## 4. 三机编队转场阶段（保留）

中心路径：

```text
(-30, 6, 0.8)
→
(-18, 6, 0.8)
```

三机横向一字槽位：

```text
drone_0 : (0,  0, 0)
drone_1 : (0, -2, 0)
drone_2 : (0,  2, 0)
```

三机配置使用声明式 3 节点期望编队图。

组级执行先集结到 `path_start` 对应槽位并获得成功 Result，再发 `path_end`。
每段仍需原生 Action 的实际到位、稳定驻留、新参考采用、安全和数据有效性通过。
固定走廊、小幅回退限制、固定世界朝向均已从业务验收中删除。

## 5. 全区间编队诊断

使用 Swarm 原源码 `SwarmGraph::calcMatrices/calcFNorm2` 的归一化 Laplacian 差的平方 Frobenius 范数。
逐样本记录最大值及均值；整体平移、旋转、统一缩放不改变指标。缺样/倒序/退化图不能作为零误差。

这只是对原机制的运动诊断；没有给该无量纲指标任意补“合格阈值”。
三节点代价路径启用、编队转场动作完成、监测业务完成分别报告。

## 6. 当前业务边界

原 `s1/s2/s3` 未定义坐标，已删除悬空引用，未补造兴趣点。
组级阶段当前是编队转场演示，不声称完成岸线载荷观测。
现有六个 a/b/c 兴趣点走单机几何观测代理和 Result 接收链路；不能据此宣称真实图像检测合格。

## 7. 条件复测

流程：

```text
初测
→ 形成观测结果
→ 结果接收
→ 判定未覆盖点
→ 必要时释放一次补测
```

规则：

- 最多一轮；
- 只补未达标点；
- 不增加原始覆盖分母；
- 安全失败时不自动重飞；
- 正常全部达标时不强行制造补测。

## 8. 请求级通过条件

完整请求 PASS 至少需要：

```text
必做任务全部完成
+ required interest points observed
+ required results received
+ formation phase complete
+ motion safety pass
+ experiment validity valid
```

覆盖率 1.0 不能覆盖安全失败。

## 9. 七机场景的位置

七机 A→B→Return、盒子障碍和扫描中断属于工程/M2 回归场景，不再作为第一版近岸监测业务实例。
