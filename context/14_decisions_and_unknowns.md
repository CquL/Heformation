## 2. V2长期候选，不构成本轮前置条件

| 事项 | V2默认建议/候选 | 尚待决定 |
|---|---|---|
| 新运动基线 | Primitive-Planner作为后续导航对照 | 同场景比较后是否替换或新增动作 |
| 上层对照 | D-ITAGS等作为离线或后续替换候选 | 不改变当前受限v9唯一在线调度器 |
| 原生执行器 | Calvo配套行为树可参考 | 当前使用本项目FormationAction，不强制引入 |
| 编队附加功能 | 保留Swarm；CAT-ORA按需 | 第一版是否需要开阔区重排 |
| 网络测试 | 先原生消息+受控条件，再评估DANCERS | 实际连接器、时钟、模型与版本 |
| 海洋模型 | Fossen/Stonefish为候选来源 | 采用的具体平台模型与控制接口 |
| 长期运行环境 | 原始例子隔离，不同时迁移 | 当前固定ROS1；长期部署另行评估 |

候选不是安装清单，更不是已完成的组件。不能因已写在AGENT中就把它当作用户最终选型。

## 4. 当前少量未知

本阶段范围和接口已冻结，按[plan.md](../plan.md)实施并以实验确认行为。长期未知包括多执行单元的合法等待/资源竞争场景、海面/水下模型与平台组成、真实通信设备参数、最终误差统计口径及研究增量；这些不阻塞当前七机AIR闭环。

能从所选上游和新工作区解决的先读取；真正缺失且影响当前动作时集中确认。不再把旧HUC版本、旧qn链路等列为阻塞新工程的必查项。
